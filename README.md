# Schedine · Cartellini

Pagina con le quote minime sui cartellini della Serie A, giornata per giornata.

- Modello: squadre + arbitro + equilibrio partita + derby.
- Arbitri: designazioni ufficiali AIA (con variazioni).
- Dati partite: football-data.co.uk.
- Si aggiorna da sola due volte al giorno (GitHub Actions) e pubblica `docs/` su GitHub Pages.

Solo a scopo di studio: le quote minime non sono consigli di gioco.
